# 07 · 终端 Markdown 渲染与排版避坑：为什么会看到 #### 与最佳排版姿势

> **测试环境**：`agy`（Antigravity CLI）+ 现代终端（Ghostty / iTerm2 / WezTerm 等），macOS 实测 2026-08-14。

用惯了漂亮的 Web 端聊天界面，第一次切到终端用 `agy` 时，很多强迫症程序员的血压瞬间就上来了：

> **“为什么它动不动就吐出来一堆带四个井号的裸文本 `#### 1. 核心问题`？终端里黑漆漆一片，完全没有层次感！”**

---

## 刨根问底：为什么终端吃不下深层标题？

这并不是你的终端仿真器（Terminal Emulator）不行，而是两层机制叠加的结果：

1. **交互式 TUI 无法直接外挂管道**：在 `agy` 的交互聊天会话里，它自己接管了终端原始输入输出（Raw Mode TUI），你没办法在会话中间插一个 `glow` 或者 `mdcat` 去实时美化。
2. **内置 Markdown 解析器的能力边界**：`agy` 的内置终端渲染器其实支持加粗（`**`）、代码块（` ``` `）、以及顶级大标题（`#` 和 `##`）。但只要模型一旦写到 3 级或 4 级标题（`###` / `####`），解析器就直接放弃治疗，原封不动把井号打在屏幕上，丑得让人心碎。

---

## 终极对策：用系统规则（Prompt 约束）驯服模型

最省心、也是效果最好的办法，就是**直接在你的全局规则（`AGENTS.md` 或 `GEMINI.md`）里明文立规矩**：

```markdown
### 终端回复排版约束
- 严禁在回复中使用 `###`、`####` 等深层多级标题语法！
- 层次化排版请统一使用「加粗小标题」配合「有序/无序列表」进行组织。
```

### 视觉效果对比（差别极大）

* ❌ **未约束时**：`#### 1. 核心业务痛点` → 终端原样输出枯燥的井号代码。
* ✅ **约束之后**：**1. 核心业务痛点** → 终端高亮加粗，下属条目缩进有序，阅读体验瞬间清爽！

---

## 衍生福利：打造极速沉浸式终端问答

如果你不需要跟它连续多轮聊天，只是想在终端里**快速查一个命令或概念**，或者想**优雅预览模型生成的 Markdown 文档**，搭配一个终端渲染神器体验会直接起飞！

### 1. 安装利器

```bash
# 首选：Go 语言开发的终端 Markdown 渲染天花板，支持 ANSI 真彩与翻页
brew install glow

# 有图场景备选：支持在 Ghostty / Kitty 中直接渲染 Markdown 内嵌图片
brew install mdcat
```

### 2. 在 `~/.zshrc` 中加入两条神仙别名

```zsh
# 一行命令向 agy 提问，并在终端里以精美排版流式展示
ask() {
  agy -p "$*" | glow
}

# 秒替 cat / less，在终端里赏心悦目地查看任何 markdown 文档
alias md="glow -p"
```

现在只要敲：
```bash
ask "解释一下 Go 语言的 channel 底层实现原理"
```
终端会通过 `glow` 渲染出带有精美边框、彩色代码高亮和加粗样式的极致输出，生产力直接拉满！
